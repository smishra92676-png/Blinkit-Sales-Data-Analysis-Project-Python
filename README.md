# Blinkit-Sales-Data-Analysis-Project-Python
🚀 **Blinkit Sales Data Analysis Project | Python**

I'm excited to share my latest **Data Analysis project on Blinkit Sales Data**, where I explored and analyzed business data using **Python**. 📊

🔹 **Tools & Technologies:** Python, Pandas, NumPy, Matplotlib, and Seaborn

📌 **Key Analysis Performed:**
• Data Cleaning and Preprocessing
• Standardized Item Fat Content categories
• Analyzed Total Sales, Average Sales, and Average Ratings
• Identified Total Sales by Item Type
• Analyzed Sales by Item Fat Content
• Compared Fat Content across Outlet Locations
• Explored Sales trends based on Outlet Establishment Year
• Analyzed Sales by Outlet Size and Location Type
• Created insightful visualizations using Bar Charts, Pie Charts, and Line Charts

This project helped me strengthen my skills in **data cleaning, exploratory data analysis (EDA), business analysis, and data visualization**.
